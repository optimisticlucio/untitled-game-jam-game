# מלך האיזמל

A game for the 2026 Shiba Game Jam, looking to assist with the [Surgical Tool Recognition for OR Nurse Training](https://medicalgamejam.pages.dev/problems/or-tool-recognition-training).

The game is an object recognition game for doctors and nurses to learn to recognize and distinguish between surgical tools. The game has a similar gameloop to מלך הפלאפל or Papa's Freezeria, with doctors requesting tools from the player, with an injection of absurdism and black humor to contrast the realistic and model-accurate surgical equipment (a dead cat's head, falafel, metallic buttplug, a 5 shekel coin).

The game is intended to be playable on mobile (so nurses and doctors can practice on their offtime), and also utilize 3d graphics (as the stated problem was that flashcards do not reflect the real state of moving 3d objects and metallic shine).
